💾 Database Backup & Restore

മുഴുവൻ ലൈബ്രറി ഡാറ്റയും സുരക്ഷിതമായി ബാക്കപ്പ് എടുക്കാനും തിരികെ റീസ്റ്റോർ ചെയ്യാനും

1. Export Full Backup (.json)

പുസ്തകങ്ങൾ, അംഗങ്ങൾ, ഇടപാടുകൾ, ഓർഡറുകൾ, സെറ്റിംഗ്സ് എന്നിവയെല്ലാം ഒറ്റ ഫയലായി ഡൗൺലോഡ് ചെയ്യുക.

2. Import / Restore Backup (.json)

നേരത്തെ ഡൗൺലോഡ് ചെയ്ത ബാക്കപ്പ് ഫയൽ തിരഞ്ഞെടുത്ത് ഡാറ്റാബേസ് റീസ്റ്റോർ ചെയ്യുക.
